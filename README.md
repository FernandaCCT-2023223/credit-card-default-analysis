# Credit Card Default Analysis

## 1. Project Overview

This project investigates credit card default risk using
the Default of Credit Card Clients dataset.

The project focuses on understanding customer characteristics,
financial behaviour and their relationship with credit card
default.

## 2. Research Question

What customer characteristics and financial behaviours
are associated with credit card default?

## 3. Project Objectives

- Understand and explore the dataset.
- Identify missing values and potential outliers.
- Perform data cleaning and preparation.
- Conduct Exploratory Data Analysis (EDA).
- Apply categorical encoding techniques.
- Apply Principal Component Analysis (PCA).
- Interpret and communicate the findings.

## 4. Dataset

Source: UCI Machine Learning Repository

Dataset: Default of Credit Card Clients

URL: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
